# Demo 视频录制指南

> 录一段 3-5 分钟的 demo 视频,放在 GitHub README / Notion 作品集 / BOSS直聘话术。
> 这是 HR 第一眼看到的东西,直接决定是否继续聊。

## 🎯 目标

让 HR / 面试官 5 分钟内看懂:
1. 这是什么 (微信小程序)
2. 核心功能 (用户填资料 → DeepSeek 生成简历 → 推荐岗位)
3. 技术亮点 (LLM 集成 + 匹配算法 + 数据看板)
4. 工程能力 (测试 + CI/CD + 监控)

## 🎬 录制流程 (3-5 分钟)

### 第一段: 开场 (0:00 - 0:30)
**画面**: 项目 logo + 一句话定位

**文案**:
> "这是简历推荐小程序,微信小程序 + DeepSeek LLM 集成。
> 用户填资料 → LLM 自动生成简历 → 语义匹配岗位库 → 推荐。
> 今天演示 3 个核心场景。"

### 第二段: 用户视角演示 (0:30 - 2:30)
**画面**: 屏幕录制 + 真人配音

**步骤**:
1. **打开小程序** (5 秒)
   - 显示登录页 (如果有 2FA)
   - 演示 code2session 自动登录

2. **填资料** (30 秒)
   - 演示完整字段 (姓名/学校/工作经历/项目/技能)
   - 演示 R115 Wizard 模式 (AI 像面试官主动提问)
   - 展示 AI 自动推断的字段

3. **生成简历** (60 秒)
   - 点"生成简历"按钮
   - **演示 DeepSeek 调用过程** (loading + 输出 JSON)
   - **展示最终简历** (Markdown / 渲染版)

4. **岗位推荐** (30 秒)
   - 展示匹配算法跑的结果
   - 显示 Top 5 推荐岗位
   - 演示 R117 Tinder 划卡 modal (可选)

### 第二段 B: 5 步 AI 求职助手 (R-JobSearch 重构后) (1:00-2:00)
**画面**: 小程序 → 首页 → "🚀 找岗位 (AI 智能匹配)" 按钮 → 5 步 tab 流

> 这是**最新版本**(R-JobSearch 重构) — 简历填完后, AI 求职助手是用户最容易展示差异化的功能。
> 5 步流程,**每步都有 AI 输出**, 而且数据都从用户自己的简历推算。

| Step | 操作 (录屏) | 配音话术 |
|------|-------------|----------|
| 1 画像 | 选 "本科 + AI 协作 + 项目经验... + 实习 + 立刻" → 点 AI 诊断 | "Step 1:用户先做 5 个画像问题。AI 诊断画像分类 + 推荐岗位池。" |
| 1 结果 | 显示 image + confidence + recommend chips | "比如这个用户是 AI 协作式,推荐 3 类岗位:产品 AI 助手 / 数据标注 / Prompt 工程师" |
| 2 项目 | 填 "简历推荐小程序" + "Express + DeepSeek" + "用 Claude 协作 90% 代码" → AI 评分 | "Step 2: 把项目扔进来, AI 评分。完成度 + AI 相关度 + 生产级 + 可展示 + 讲故事, 5 个维度" |
| 2 结果 | 看到 7.x + 5 项 breakdown + 改进建议 + STAR 故事点 | "这个项目 7 分,AI 还指出 3 个改进点 + 给我写了 3 个 STAR 故事点预览" |
| 3 匹配 | 自动加载 resume_id → 点开始匹配 → 看到 verify_status 标识 | "Step 3:自动拉简历 ID (不用用户填),点匹配。每个岗位有 verify 状态(✓ 已验证 / ⚠ 待复查 / ○ 未验证)+ 1-10 分" |
| 3 操作 | 点某个岗位的 "📮 标记已投" → 自动写到追踪列表 | "一键标记投递,数据进 Step 5 追踪列表" |
| 4 生成 | resume_id 自动 + 点 AI 生成 → 等 5-8s | "Step 4:AI 生成完整简历 + STAR 故事点。每个故事点都有 Situation/Task/Action/Result 完整 STAR,面试直接念" |
| 4 结果 | 看到 3-5 个 STAR 卡 + 简历文本 | "这 3-5 个故事点是项目复盘的核心,面试时被问'你最有成就感的项目'可以直接背" |
| 5 追踪 | 看到投递列表 + 4 个状态按钮 | "Step 5:投递追踪。HR 已看 / 面试 / 发 offer / 拒绝,每条状态都可改。还有'该跟进了'提醒" |

### 第三段: 技术演示 (2:30 - 4:00)
**画面**: 后台 / 代码 / 监控

## 🛠️ 录制工具

### 屏幕录制
- **Mac**: QuickTime Player → File → New Screen Recording
- **Windows**: OBS Studio (免费) / Xbox Game Bar (Win+ G)
- **手机**: 微信开发者工具 → 远程调试 + 屏幕镜像

### 视频编辑
- **剪映** (免费,中文) — 加字幕/转场/音乐
- **CapCut** (国际版)
- **iMovie** (Mac)

### 字幕/配音
- **字幕**:剪映自动字幕
- **配音**:Mac 系统自带"说普通话"功能 / 讯飞配音 / 自己录

## 📐 输出规格

| 维度 | 规格 |
|------|------|
| 分辨率 | 1920×1080 (横屏) 或 1080×1920 (竖屏) |
| 时长 | 3-5 分钟 (太长没人看) |
| 格式 | MP4 (H.264) |
| 大小 | < 100MB (上传 GitHub) |
| 字幕 | 必须有 (静音播放也能看) |
| 背景音乐 | 轻音乐 (音量 < 配音) |

## 🎬 录制脚本 (配音稿)

### 开场 (15 秒)
> "这是简历推荐小程序 —— 微信小程序 + DeepSeek LLM 集成。
> 用户填资料,AI 自动生成简历,然后推荐匹配的岗位。"

### 用户填资料 (30 秒)
> "用户在小程序填资料,字段包括工作经历、项目、技能。
> 这里用了 Wizard 模式,AI 像面试官一样主动提问,
> 自动推断用户没填的字段,比如行业、岗位偏好。"

### 生成简历 (45 秒)
> "点生成,后端调用 DeepSeek LLM。
> Prompt 模板约束输出格式 (JSON),retry 机制处理格式错误。
> match rerank 用 LLM 做语义匹配,把简历和岗位库对齐。"

### 推荐 (30 秒)
> "匹配结果按相关度排序,展示 Top 5 岗位。
> 用户可以 Tinder 划卡快速浏览,或者直接查看详情。"

### 5 步流 (R-JobSearch 重构后 — 重点演示)(60 秒)
> "新版核心功能:AI 求职助手 5 步流。
> Step 1 用户做 5 个画像问题,AI 立刻告诉用户是什么类型、推荐什么岗位。
> Step 2 把项目扔进来,AI 评分 5 个维度,还给出 STAR 故事点 — 面试直接用。
> Step 3 自动匹配岗位库,每个岗位都有 verify 状态(已验证 / 待复查)+ 1-10 分。
> Step 4 AI 生成完整简历 + 3-5 个 STAR 故事,标准化输出,STAR 故事点面试被问'最有成就感的项目'直接背。
> Step 5 投递追踪 — HR 已看 / 面试 / 发 offer / 拒绝 一键更新状态。
> 关键:每步有 AI 输出,但用户能掌控节奏;每步数据都进数据库,可追溯。"

### 工程能力 (45 秒)
> "后台有 114 单测 + 11 e2e smoke 全绿。
> GitHub Actions 4 个 workflow (test / deploy / upload / perf 门禁)。
> Sentry 错误监控 + 告警 + 审计 + 2FA。
> PM2 + nginx + certbot + Let's Encrypt + 7 天自动备份。"

### 结尾 (15 秒)
> "简历推荐小程序,生产级已上线。
> 完整工程能力,完整 LLM 应用,完整 DevOps。
> 作品集 aigc.crlcrl.com。"

## ⚠️ 不要做的

1. **不要超过 5 分钟** — 没人看
2. **不要无配音纯音乐** — HR 不听
3. **不要无字幕** — 静音播放也要能看
4. **不要展示所有功能** — 只展示 3-5 个核心
5. **不要露个人隐私** — 演示数据用 fake
6. **不要造假数据** — 用真实 demo 数据
